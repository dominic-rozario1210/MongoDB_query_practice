# MongoDB Practice Questions

## Description
This repository contains basic MongoDB practice queries for retrieving and filtering student records.

## Topics Covered
- `find()` and `findOne()`
- Filtering documents
- Field projection
- Selecting specific fields
- Querying by name, age, course, and city

## Technology Used
- MongoDB
- MongoDB Query Language (MQL)

Completed 15 practice questions as part of Node.js Backend learning.
